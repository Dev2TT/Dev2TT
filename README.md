## `01` — SOBRE MIM

Sou desenvolvedor com foco em **desenvolvimento full stack, dados e automação**.

Meu interesse está principalmente no que acontece por trás das interfaces: **APIs, bancos de dados, processamento de informações, integrações e sistemas automatizados**, mas também tenho curiosidade de como é construído as interfaces web. 

Atualmente estou aprofundando meus conhecimentos em:

```text
Python                        → Backend
PostgreSQL                    → Banco de dados
FastAPI                       → APIs
Docker                        → Containers
Linux                         → Ambiente
HTML, CSS e Javascript        → Front-End
```

Meu objetivo é transformar conhecimento em **projetos funcionais e soluções reais**.
